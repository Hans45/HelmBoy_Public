Detailed Description

Utilitaires mathématiques et helpers pour mopo (interpolation, buffers, conversions).

Contient fonctions rapides pour le traitement numérique (sin approximatif, conversion fréquence/midi, utilitaires de buffer SIMD-friendly) et petits concepts utilitaires.
